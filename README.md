# Intelligent Dehradun Traffic Management System

## About the Project
This project helps users find routes in Dehradun using a road network
and shortest-path algorithms.

## Features
- Find routes between locations.
- Shortest-path calculation using Dijkstra's algorithm.
- Road network data from OpenStreetMap.
- Web-based interface for route search.

## Technologies Used
- HTML
- CSS
- JavaScript
- Python
- Flask
- OpenStreetMap

## How to Run
1. Clone the repository.
2. Install the required dependencies.
3. Run the Flask application.
4. Open the application in a web browser.
